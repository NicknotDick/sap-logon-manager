# SAP 登录管理器 · 使用说明

一个**免安装**的 Windows 小工具：把 SAP Logon 里的连接和账号密码管起来，双击就进系统，不用每天手输。

当前版本：**v1.6.5**（[下载最新版](https://github.com/NicknotDick/sap-logon-manager/releases/latest)；zip 版与单文件绿色版任选其一）

- 单文件绿色版：`SAP登录管理器.exe`，双击即用，不写注册表、不装运行时
- 自动读取本机 SAP Logon 配置，一键同步
- 凭据 AES-256-GCM 加密，只存在本机
- 支持批量登录、分组收藏、事务码直达、脚本绑定、导入导出
- 同一连接下多客户端 × 多账号，右键平铺选账号、悬停选 ZH / EN 语言登录（适合海外双语项目）
- 主题可跟随系统深浅色；检查更新支持每日自动提示 + 手动检查

> 完整双语手册见仓库根目录 `SAP登录管理器-操作使用手册-User-Manual.pdf`（含演示截图，无任何真实环境数据）。

## 一、环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11（64 位） |
| SAP 客户端 | SAP GUI for Windows 7.40 及以上（已在 8.0 实测通过） |
| 权限 | 普通用户即可，无需管理员 |
| 网络 | 首次运行不联网；仅在你登录 SAP 时访问你的 SAP 服务器 |

> 本工具只是调用 SAP 官方的 `sapshcut.exe` / `saplogon.exe`，不修改 SAP GUI 任何文件，也不会回写你的 SAP Logon 配置。

## 二、首次使用（约 1 分钟）

1. **双击 `SAP登录管理器.exe`**。
2. **主密码是可选的**（v1.6.0 起）：
   - 默认**不启用**主密码保护 → 直接进入程序，开始用（凭据仍以 AES-256-GCM 加密存放，但解密密钥不依赖用户输入）
   - 勾选「启用主密码保护」→ 设置至少 6 位主密码，之后每次打开需输入
   - 随时可在「设置 → 安全」里查看当前状态，或点「修改主密码」启用
3. 进入主界面后点右上角 **「自动获取现有配置」**（快捷键 `F5`），程序会扫描本机 SAP Logon 配置并列出全部系统。
4. 双击某个系统（或点它右侧的「登录」），填入账号密码，勾选「保存密码并自动登录」，保存。
5. 之后再登录，双击即直达系统界面。

> 未启用主密码时，安全性依赖 Windows 账户登录与文件权限（凭据文件仅当前用户可读）；共享电脑上建议启用主密码。启用后若主密码遗忘，已保存凭据**无法恢复**（这是加密的设计，不是缺陷），建议在设置里定期导出一次加密备份。

```
│ 生产系统   │ ☐ QAS  DEMO_QAS               ← 勾选后可批量  │
│            │ ☐ PRD  DEMO_PRD                              │

│  新建分组  │                                                 │
├────────────┴─────────────────────────────────────────────────┤
│ SAP GUI 8.0  上次同步：10-27 14:50          已选 1 项  已解锁 │
└──────────────────────────────────────────────────────────────┘
```

**每行信息**：环境徽标（DEV 绿 / QAS 橙 / **PRD 红**）· 系统名 · SID · 连接方式 · 上次登录时间 · 客户端 · 连通性圆点 · 收藏星标 · 登录按钮。

**环境徽标**：按名称/SID 自动推断，可在「编辑连接」里手动指定。生产系统默认在登录前二次确认。

**连通性圆点**：绿色可连通、红色不可达、黄色检测中。经 Router 的系统探测的是 Router 端口（3299），负载均衡系统探测消息服务器（3600）。

**连通状态即时刷新（v1.6.0 起）**：
- **窗口回到前台**（从托盘恢复、切回本程序）→ 立刻重新探测一次
- **窗口内有操作**（鼠标移动/点击、键盘、滚轮）→ 满足节流条件后立刻重新探测
- 节流规则：操作判定窗口 3 秒，最小探测间隔 30 秒；窗口隐藏（最小化到托盘）时不探测
- 探测为 TCP 连接（1.5 秒超时），只连 SAP 端口，不做 ICMP ping，不产生 SAP 登录动作

## 四、自动获取现有配置（同步）

点 **「自动获取现有配置」** 或按 `F5`：

- 重新读取 `%APPDATA%\SAP\Common\SAPUILandscape.xml`（含全局配置与 `<Includes>` 引用），旧版安装回退 `saplogon.ini`
- 与本地清单合并：

| 情况 | 处理 |
|---|---|
| 新系统 | 追加，标「NEW」，保留你的分组/收藏 |
| 连接参数变了 | 更新 host/端口/Router/备注，**凭据、收藏、分组、脚本绑定都保留** |
| 系统改名 | 同步新名称（否则按名称定位会失配），提示「已更名」 |
| 系统被删了 | 标「失效」置灰置底，**不删除**，凭据仍在，可手动删 |
| 自己手工加的连接 | 完全不受同步影响 |

- 每次同步前自动快照，可在「设置 → 数据与诊断 → 回滚到最近快照」还原
- 配置文件读坏时不覆盖旧清单，只报错，不会把列表清空

> 程序启动时会静默同步一次；SAP Logon 配置发生变化（例如你新建了系统）时也会自动同步。

## 五、批量登录（掉线后一键全拉起）

1. 在列表左侧勾选多个系统（可跨分组，结合搜索框快速筛）。
2. 底部出现「登录选中 (n)」→ 或点顶部 **「批量登录」**。
3. 弹窗中可「开始登录」，逐条显示 成功 / 需手输 / 失败 / 跳过，可随时中止。

- 默认顺序执行、间隔 3 秒（设置里 1–10 秒可调），避免会话争抢
- 勾选「跳过不可达系统」可自动跳过探测失败项
- 失败**不会自动重试**，避免账号被锁
- 结束可「复制结果」留档

## 六、凭据与安全

| 机制 | 说明 |
|---|---|
| 加密 | 主密码经 PBKDF2-HMAC-SHA256（20 万次）派生密钥，凭据用 **AES-256-GCM** 认证加密，存 `vault.dat` |
| 记住主密码 | 可选。用 Windows **DPAPI** 封装，仅当前 Windows 账户能解；换电脑需重新输主密码 |
| 闲置锁定 | **默认 0（不自动锁定）**，设置可调 0–720 分钟；锁定后需重新输主密码 |
| 登录方式 | 默认允许密码走命令行（`sapshcut -pw`），登录更直接；可在设置中关闭，改走「临时 `.sap` + 登录框自动填表」，此时**密码不出现在命令行**，文件用后立即覆写并删除 |
| 兜底 | 临时文件失败时降级为「让 SAP 自己弹密码框」；关闭命令行密码后由程序自动填表接管弹框 |
| 日志 | 只记录事件与错误码，**从不记录密码** |
| 明文窗口 | 临时 `.sap` 在磁盘上存在数秒（SAP 需要读取），目录仅当前用户可访问；首次运行会有安全提示 |

## 六·补、多客户端 × 多账号（数量不限）

同一个连接下可以保存**任意多个客户端**，每个客户端下又可保存**任意多个账号**，账号总数不设上限。例如客户端 100 存账号 1~4、客户端 300 存账号 1~4、客户端 500 存账号 1~2，凭据彼此独立（同名账号在不同客户端也互不冲突）。

**管理账号**：右键连接 →「编辑凭据…」（或新增连接时直接填）

```
客户端      [ 300        ▾ ]   [ 新增账号 ]

已保存账号 4 个（不限数量） · 登录过的客户端：100 / 300 / 500
  ┌───────────────────────────────┐
  │ ● DEMO_USER_A         默认    │   ← ● 和「默认」标出默认账号
  │   DEMO_USER_B                 │
  │   DEMO_USER_C                 │
  └───────────────────────────────┘
  [ 设为默认 ]  [ 删除账号 ]

账号      [ DEMO_USER_A   ]
密码      [ ••••••••      ]
保存密码并自动登录 ☑
```

| 操作 | 说明 |
|---|---|
| 新增账号 | 点「新增账号」，填账号密码后保存；每个客户端的第一个账号**自动成为该客户端的默认**；数量不设上限 |
| 设为默认 | 选中某账号点「设为默认」，同客户端的其它账号自动取消默认；各客户端各有一个默认 |
| 删除账号 | 确认即写盘（即时生效）；同名重复时保留带姓名的条目并合并空字段；删默认账号会自动把剩余账号提升一个为默认 |
| 切换客户端 | 下拉列出该连接已保存过的全部客户端，也可直接输入新客户端号；账号列表随之切换，**未保存的编辑不会丢失** |
| 保存 | 一次保存同步所有已切换过的客户端，凭据库只加密写盘一次 |

**登录时选客户端与账号**：右键连接，账号逐条平铺；文字不再直接带语言，语言放到二级菜单。

```
登录（默认）                          Enter   ← 默认项带 Enter 标记
  100 · DEMO_USER_A（张三）
  100 · DEMO_USER_B（李四）
  300 · DEMO_USER_A（张三）
  500 · DEMO_USER_C
  ─────────────
  编辑凭据…
```

- 每行格式为「客户端 · 账号（姓名）」，客户端仅显示数字；姓名为空时不显示括号
- 带 `Enter` 的一行是默认账号；同一账号只出现一次（默认项已列出则不再重复平铺）
- **直接点账号文字** → 按该账号保存的语言登录（默认 ZH）
- **鼠标悬停到账号文字右方的空白/箭头区域** → 展开 `ZH` / `EN` 二级菜单，点某个语言即以该账号 + 所选语言登录。**这一条对海外 SAP 双语项目尤其实用：同一套系统，国内同事用中文界面、海外同事用英文界面，不必为语言单独配一条连接。**
- 双击系统行或按 `Enter` → 用默认账号按其配置语言一键登录
- 快速搜索窗（`Ctrl + Alt + S`）的结果行同样支持整行右击选账号 + 语言，菜单与主窗口一致
- 批量登录始终使用各系统的默认账号

主列表的连接信息行也会显示默认账号名（蓝色），一眼看出当前默认是谁。

## 六·补二、登录方式（务必了解）

### 两条关键的技术事实

本机的登录链是围绕这两个实测结论搭起来的，改动前请先了解：

**事实一：SAP GUI 7.40 PL1 起，`.sap` 文件里的密码字段被官方彻底废除**（SAP Note 146173）。SAP 官方安全指南的原话是：该功能被禁用，因为任何人都可以复制一个含密码的 `.sap` 文件、冒充他人登录甚至改密。

所以在 SAP GUI 8.0 上：

| `.sap` 里的字段 | 是否还有效 |
|---|---|
| `Description=`（显示名，用于定位系统） | ✅ 有效 |
| `[User] Name=`（账号） | ✅ 有效，会填入登录框 |
| `[User] Password=`（密码） | ❌ **被 SAP 直接忽略** |
| `GuiParm=`（连接串） | ✅ 有效 |

**事实二：负载均衡系统必须带 `GuiParm`，否则静默失败。** 示例 `DEMO PRD` 在 landscape 里的定义是 `server="SAPGRP"`——这是个**占位符**，真实连接信息只在 `Messageserver` 节点（`s4prdascs.example.com`）里。不带 `GuiParm` 时 SAP 解析不出连接，**连进程都不起，也不弹任何框**（实测）。

> 这也解释了一个很误导人的历史现象：早期版本有时"登录成功"、有时弹密码框。成功的那几次，是 `[Options] Reuse=1` **复用了已经开着的会话**，压根没校验密码；一旦会话关了，就必然弹框。不是密码时对时错，是 `.sap` 从来没有把密码送出去过。

### 现在的登录链

> **v1.5.3 起，默认走「命令行带密码」路径**（`sapshcut -system=... -pw=...`），登录最直接、不依赖弹框接管。下列「.sap + 自动填表」是**关闭该选项后的安全路径**，内容仍然有效：

```
1. 生成临时 .sap：Description=显示名 + GuiParm=连接串 + 账号（**不带密码**）
2. sapshcut.exe -open <file>          → SAP 按显示名从本机 landscape 精确定位
3. SAP 弹出登录框（标题就是系统显示名，如「DEMO PRD」）
4. 程序自动填入密码并点击「登录」    ← 密码在这里才出现，只进内存，不落盘、不进命令行
5. 会话窗口出现 → 登录成功
```

**为什么把第 4 步做成自动填表，而不是命令行 `-pw`：**（默认已改为命令行优先；以下对比说明自动填表路径在「安全」维度的优势）

| 方案 | 定位能力 | 密码去向 | 重名 SID |
|---|---|---|---|
| `.sap` + 自动填表（当前主路径） | ✅ 按显示名，全系统可用 | 只进目标进程内存 | ✅ 安全 |
| `sapshcut -system=<SID> -pw=` | ✅ 可用 | **出现在进程命令行** | ❌ 会连错系统 |
| `sapshcut -sysname=<显示名> -pw=` | ❌ XML landscape 下解析不了（实测弹「快捷方式属性」） | 出现在命令行 | ✅ |

命令行那条路实测还有两个坑：`-sysname` 对 XML landscape 里的负载均衡条目**无法定位**；`-guiparm` 会覆盖 landscape 解析，连接串拼不全时**静默失败**。

### 自动填表的安全底线

程序往 SAP 登录框填密码前，会先做三重校验，任一不满足就绝不填：

1. **只认 SAP 进程**：窗口必须属于 SAP 安装目录下的 `saplogon.exe` / `sapgui.exe` / `sapshcut.exe`——任何伪造的同结构窗口都骗不走密码；
2. **只认本次目标**：标题里的 SID 与客户端必须与本次登录一致，防止把 PRD 的密码填进 QAS 的框；
3. **一次登录最多填 1 次**：弹框往往意味着密码已被拒绝，重复填同一个密码毫无意义，还会把账号试锁。

填表用的是标准 Win32 消息（`WM_SETTEXT` / `BM_CLICK`），写入后会读回校验，**不注入 DLL、不模拟键盘、不做全局钩子**。

### 如果还是弹出登录框

无论走命令行带密码还是自动填表路径，弹框都意味着凭据**确实送出但被 SAP 拒绝**。按可能性排序：

1. **密码已过期**（最常见）。SAP 定期强制改密，改完后旧密码立即失效。右键连接 →「编辑凭据」填入新密码。
2. **账号被锁定**。连续输错几次就会锁，表现是"刚才还能登，突然全系统都不行，过一段时间又行了"。找 BASIS 管理员解锁。
3. **选错了账号 / 客户端**。右键菜单每行是「客户端 · 账号（姓名）」，可辨认这次用的是哪条；同一账号在不同客户端独立存在，800 有账号不代表 500 也有。
4. **连接名对不上**。显示名称须与 SAP Logon 里完全一致，否则可能连到同 SID 的另一套系统。

**怎么确认是哪一种**：日志在 `%LOCALAPPDATA%\SapLauncher\logs\`，会记录当时屏幕上所有对话框标题，例如：

```
[WARN] 命令行带密码后 SAP 仍弹出登录框：DEMO PRD；对话框：[DEMO PRD | SAP Logon 800 | 修改密码]
```

- 出现「修改密码」→ 密码到期
- 只有系统名 → 密码错误或账号被锁

程序底部提示条也会直接给出结论，例如「SAP 拒绝了账号 89****92（客户端 800）：密码错误、已被修改，或账号被锁定」。

### 「SAP GUI 安全性 / 快捷方式文件」确认框

如果看到这个对话框（标题「SAP GUI 安全性」，内容提示「是否要以指定 OK 代码登录到此系统？」）：

**原因**：你在该连接上配了**事务码**（如 `/nSE16N`）。SAP 对"快捷方式文件自动执行事务码"有安全确认机制，每次都会问一遍。

**已默认关闭**：程序现在默认**不把事务码写进自动登录的快捷方式**，所以这个框不会再出现——登录后直接进入系统，事务码在右上角命令栏输入即可（SAP 会记住你常用的事务码）。

**仍然想直达事务码**：编辑连接 → 登录凭据 → 勾选「**登录后直达事务码**」。此时可以：

1. 在 SAP 的确认框里勾选「**记住我的决定(R)**」再点允许
2. 程序的临时文件名已改为**按 系统+客户端+账号 固定**（如 `login-78886602f1983844.sap`），SAP 的"记住"是按文件路径生效的，所以勾一次以后就不再问

> 旧版本临时文件名每次都是随机 GUID，导致「记住我的决定」勾了也白勾——这是之前每次都弹框的第二个原因。

## 七、导出 / 导入 / 分享

**设置 → 数据与诊断**：

- **导出**：生成 JSON。默认只含连接信息；选择「包含凭据」时会要求设置一个**导出密码**，凭据单独加密后再写入
- **导入**：先预览（新增 / 覆盖 / 跳过），可勾选「覆盖同名连接」「同时导入分组」，导错可在设置里回滚快照
- **分享给同事**：右键连接 →「复制连接信息」，生成不含密码的文本卡片，可直接粘贴到 IM

## 八、脚本管理（可选）

登录成功后自动执行 SAP GUI 脚本（VBScript）。

1. 任意连接右键 →「绑定脚本…」→ 「新建脚本」或「导入 .vbs」
2. 编辑器内可「试运行」；保存后点「绑定到当前连接」
3. 该连接下次登录成功（检测到会话窗口）后，按顺序用 `cscript` 执行

> 需要服务器端启用 `sapgui/user_scripting = TRUE`，且客户端勾选「启用脚本」。不满足时脚本会失败并提示，但**不影响正常登录**。

## 九·补、主题与检查更新（v1.6.4 / v1.6.5）

**主题（设置 → 通用 → 主题）**：三种模式 —— `跟随系统` / `深色` / `浅色`。

- 选「跟随系统」时按 Windows 应用深浅色自动切换；在 Windows 设置里改颜色模式，已打开的窗口即时跟随，无需重启，标题栏同步
- 手动选深色或浅色则固定不变；系统颜色读不到时回退深色
- 仅影响界面配色，不涉及连接、登录与凭据

**检查更新**：两种方式。

- 每天首次启动时后台静默检查一次 GitHub 最新版本，**只有发现新版本才弹提示窗**；已是最新或网络失败均不打扰
- 随时可在「关于」窗口点「**查找更新**」手动检查
- 提示窗显示最新版本号、发布时间与更新摘要，提供「查看新版本」/「稍后再说」；选前者按当前运行形态自动匹配安装包（zip 版下 zip、单文件版下单文件 exe），用默认浏览器打开下载；无对应附件则打开发布页
- 检查更新需联网，但**只读取 GitHub 公开发布信息，不上传任何本机数据**；每日检查日期记在数据目录 `update-check.txt`，当天失败不重试，可随时手动检查

## 十、数据位置与迁移

所有数据在：`%LOCALAPPDATA%\SapLauncher`

```
manifest.json   连接清单、分组、设置（不含密码）
vault.dat       AES-256 加密的凭据
autologin.bin   DPAPI 封装的「记住主密码」（不可跨机）
scripts/        VBS 脚本库
logs/           日志，按日轮转保留 7 天
backup/         同步快照，保留最近 5 份
update-check.txt   每日检查更新的日期标记
```

**换电脑**：拷贝 `vault.dat` 到新机器的同一路径，首次启动输入原主密码即可解密（`autologin.bin` 不要拷，拷了也解不开）。

## 十一、故障排查

| 现象 | 原因 / 处理 |
|---|---|
| 提示「未检测到 SAP GUI」 | 未安装 SAP GUI，或安装在被裁剪的非标准目录。程序会尝试注册表与标准路径，仍失败请安装 SAP GUI for Windows |
| 列表里没有系统 | 点「自动获取现有配置」；确认 SAP Logon 里能看到条目；看 `logs` 里的同步警告 |
| 登录后连到**另一套**系统 | 你的 SAP Logon 里存在同名 SID（如两个 DQ1）。本程序按「显示名称」精确定位，请勿手工改乱名称；必要时在条目属性里改用 GuiParm 连接组 |
| 点击登录没反应 | 看状态栏与日志。常见原因：服务器不可达、账号被锁、需要先改密码。可用「右键 → 登录」走 L3 让 SAP 自己弹密码框 |
| 热键无反应 | 被其它程序占用。设置里换一个组合后重启程序 |
| 关闭窗口后找不到程序 | 默认最小化到托盘，双击托盘图标或按热键呼出；设置里可关闭该行为 |
| 杀软报警 | 程序会调用 SAP 官方程序并写临时文件。若被拦截，请加入信任；也可在设置中关闭「允许密码出现在命令行」以降低敏感行为 |

## 十三、跨 SAP 版本兼容 & 换电脑使用

### 支持的 SAP GUI
- SAP GUI **7.20 及以上**（7.40 / 7.50 / 7.60 / 7.70 / 8.0）：自动读取 `SAPUILandscape.xml`。
- 更早版本（`saplogon.ini`）：自动回退读取 INI 配置。
- **32 位 / 64 位**安装都支持：注册表（含 `WOW6432Node`）+ `Program Files` 与 `Program Files (x86)` 双路径查找。
- 「登录后直达事务码」使用 SAP 官方参数 `-type=Transaction -command=<事务码>`（SAP Note 103019，6.x 起支持），并兼容 `.sap` 的 `[Function]`，跨版本通用。
- 登录框自动填密码针对标准 SAP 登录对话框；若某版本结构不同，会自动放弃并回落到手工输入，不会误填。

### 换到另一台电脑
前提：目标电脑需装有 **SAP GUI**（本程序只调用它），且该机能正常登录 SAP。

三种迁移方式，任选其一：
1. **整包便携（推荐）**：把程序放在一个文件夹里，在 exe 同目录新建名为 `data` 的子文件夹，程序就会把数据存到 `data\`。已有数据时，先把旧电脑 `%LOCALAPPDATA%\SapLauncher` 里的文件复制进这个 `data\`；之后把「exe + data 文件夹」整个拷到新电脑即可。（也可在「设置 → 数据与诊断」点「切换为便携模式」，程序会自动复制并重启）
2. **复制数据目录**：把旧电脑的 `%LOCALAPPDATA%\SapLauncher` 整个文件夹复制到新电脑同一位置。
3. **导出 / 导入**：在程序里「导出」（可勾选包含凭据并设置导出密码）→ 把文件拷到新电脑 →「导入」。

注意：
- 凭据用主密码加密；「记住主密码」绑定当前 Windows 账户（DPAPI），**换电脑后首次需重新输入一次主密码**，之后可再勾选记住。
- 换电脑后如连接列表不对，先在「设置」里点「自动获取现有配置」同步本机 SAP Logon。
